# Trilha da Carreira

Trilha interativa com 16 aulas sobre mercado de trabalho, tecnologia, marketing, empreendedorismo e carreira.

Abra [`index.html`](index.html) no navegador para percorrer as aulas. O progresso fica no armazenamento local do navegador. O [roteiro de documentação em PDF](Roteiro%20de%20Documenta%C3%A7%C3%A3o%20%E2%80%94%20Trilha%20da%20Carreira.pdf) acompanha o material.
